An IntelliJ plugin that removes the last obstacles between you and not working.

## What it does

| Feature | Behaviour |
|---|---|
| Bongo cat | Sits in the bottom-right corner of the editor and drums while you type. Moves to the bottom-left when you type underneath it. Does a flip on Enter. |
| Rainbow runner | A cat with a rainbow trail runs along the top of the editor. The faster you type, the more visible and faster it gets. Fades out a few seconds after you stop. |
| DVD bouncer | After 30 seconds without a keystroke, a "DVD" box bounces around the editor and changes colour on every wall. Corner hits strobe. |
| Save boom | Saving plays a boom. Saving repeatedly within two seconds raises the pitch. |
| Feed panels | Three tool windows on the right: YouTube Shorts, TikTok, Instagram Reels. Each clip plays once, then the feed advances by itself. All three can be open at once. Closing a panel stops its page. |
| Ad-host blocking | Requests from the feed panels to hosts on the AdGuard DNS filter are cancelled. The list is downloaded at most once a day. Sponsored items inside the feeds are not removed. |
| Comic Mono | The editor font is set to Comic Mono and set back whenever it is changed. |

Everything except the feed panels is switched by **Tools → Brainrot Mode**. Switching it off restores your previous font.

## Required plugins

The IDE refuses to load Brainrot without these.

| Plugin | ID | Note |
|---|---|---|
| [Ridiculous Coding](https://plugins.jetbrains.com/plugin/30712-ridiculous-coding) | `com.bryantjames.ridiculouscoding` | Any version. |
| [Nyan Progress Bar](https://plugins.jetbrains.com/plugin/8575-nyan-progress-bar) | `some.awesome` | Pinned to 1.16, see below. |

Uninstall any other progress bar plugin and the original Typing-Bongo-Cat plugin first.

### Nyan Progress Bar pin

Version 1.16, as served by the JetBrains Marketplace, was reviewed at bytecode level: it only draws, and makes no file,
network, process or reflection calls. The plugin itself is not redistributed here; only its hash is recorded.

```
ac04a24324960494da76cfe08f1952d29d2e4bdf82ee5432f3048f7e7d022ed7  NyanProgressBar.jar (1.16)
```

At IDE start Brainrot hashes the installed Nyan Progress Bar and shows a warning if it differs. It only warns. The IDE
has no per-plugin update lock, so the hard stop is switching off automatic plugin updates.

If the warning appears, the Marketplace copy is no longer the reviewed one. Nothing is blocked; whether to trust the
newer build is your call.

## Install

Requires IntelliJ IDEA 2025.3 or later.

1. Open the [latest release](../../releases/latest) and download `brainrot-<version>.zip` under **Assets**. Do not
   unpack it.
2. In the IDE open **Settings → Plugins** (macOS: `⌘,`, Windows/Linux: `Ctrl+Alt+S`).
3. Click the gear icon at the top of the Plugins page → **Install Plugin from Disk...** → pick the zip.
4. Accept the prompt to install the required plugins (Ridiculous Coding, Nyan Progress Bar).
5. Click **Restart IDE**.

After the restart there are three new buttons on the right edge (YouTube Shorts, TikTok, Instagram Reels) and a
**Tools → Brainrot Mode** menu entry. To update, repeat with the newer zip.

If no prompt appears, install the two required plugins from the **Marketplace** tab and restart.

## Build

```
./gradlew buildPlugin
```

Needs JDK 21. The build compiles against the IDE installed at `/Applications/IntelliJ IDEA.app`. With `CI=true` set it
downloads IntelliJ IDEA 2025.3 instead.

## Releases

Every push to `main` that touches more than Markdown is built by GitHub Actions and published on the
[releases page](../../releases) with the plugin zip attached. The version comes
from the commit subjects since the previous release:

| Commit subject | Bump |
|---|---|
| `feat: ...` | minor |
| `feat!: ...`, `fix!: ...`, or `BREAKING CHANGE` in the body | major |
| anything else | patch |

Local builds are labelled `0.0.0-dev`.

## Swapping sprites and sound

Replace `runner.png`, `bouncer.png` or `boom.wav` in `src/main/resources/brainrot/` and rebuild. The shipped ones are
placeholders generated by `python3 tools/make_assets.py`.
